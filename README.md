# KÜL TAHTI — ASCII Dark Fantasy RPG

Godot 4.3+ ile geliştirilen, tamamı ASCII karakterlerinden oluşturulan top-down karanlık fantastik RPG prototipi.

**0.3 – Ashen Forest:** Prosedürel çok katmanlı orman, yağmur, hareketli nehir, gün-gece, düşman, üç silah, büyü ve ağaç kesme. Görünür dünyanın tamamı özel ASCII font atlası üzerinden GPU ile işlenir.

**Kontroller:** WASD yürüme, Shift koşma, 1/2/3 silah, Space saldırı, Q büyü, E ağaç kesme, R yağmur, T zaman, H arayüz.

**Godot:** project.godot dosyasını Godot 4.3+ ile aç. F5 ile test et.

**Web:** \`.github/workflows/web.yml\` Godot Web export ve Pages dağıtımını otomatik yapar. GitHub Pages bir kez **Settings → Pages → Source: GitHub Actions** seçilerek etkinleştirilmelidir.

Bu bir dikey dilim / görüntü geliştirme prototipidir, tamamlanmış RPG değildir. Görsel referanslarla birebir eşleşme iddiası yoktur.
